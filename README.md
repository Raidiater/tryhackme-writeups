## Pre-Security Highlights

- **Network Fundamentals:** OSI model, TCP three-way handshake, UDP, common ports, and how firewalls, VPNs, and VLANs fit together
- **How the Web Works:** DNS record lookups with `nslookup`, HTTP methods (GET/POST/PUT), status codes, and finding credentials leaked in page source
- **Operating Systems:** Windows and Linux lab environments, kernel vs. user space, and a user-switching lab covering weak passwords and exposed command history
- **Offensive Tools:** directory enumeration with Gobuster and dirb, and credential brute-forcing with Hydra
- **Defensive Mindset:** prevention, detection, mitigation, analysis, response, and improvement, plus SOC alert triage in a simulated dashboard
- **Cryptography Basics:** CIA Triad, plaintext/ciphertext/keys, and a Caesar cipher lab

## What This Demonstrates

- Understanding of how network and web traffic work, which is the foundation for reading logs and packet captures
- Familiarity with attacker techniques (enumeration, brute force) and how they show up in logs and alerts
- Consistent documentation habits, with every lab backed by screenshots and written up in my own words
